# 3 分钟拿到公网链接（手机 + 电脑都能打开）

国内推荐 **Gitee Pages**，不用翻墙。

## 第 1 步：注册/登录 Gitee（约 1 分钟）

浏览器打开：https://gitee.com/signup

- 手机号注册，登录
- 记住你的**用户名**（个人主页地址里那一段）

## 第 2 步：新建仓库（约 30 秒）

打开：https://gitee.com/projects/new

按下面填：

| 项 | 填写 |
|----|------|
| 仓库名称 | `campus-app-demo` |
| 路径 | 默认（一般等于用户名/仓库名） |
| 是否开源 | **选开源** |
| 初始化仓库 | **不要勾选**（不要 README） |

点「创建」。

创建后地址类似：`https://gitee.com/你的用户名/campus-app-demo`

## 第 3 步：一键推送到仓库

1. 复制仓库页上的 **HTTPS 克隆地址**  
   （形如 `https://gitee.com/你的用户名/campus-app-demo.git`）
2. 双击本目录 **`部署到GiteePages.bat`**
3. 粘贴地址，回车，等它推完

## 第 4 步：开启 Gitee Pages

1. 打开你的仓库页
2. 左侧菜单找 **服务 → Gitee Pages**
3. 点 **启动**（免费版可能要手机实名/绑定，按提示做）
4. 启动后会显示访问地址，一般是：

```
https://你的用户名.gitee.io/campus-app-demo/
```

把这个链接发到手机微信/电脑浏览器，都能直接打开。

## 常见问题

**Pages 要实名？**  
要。Gitee 免费 Pages 需要实名认证，一次即可。

**推送到一半要账号密码？**  
弹出登录时，用户名填 Gitee 用户名，密码填你设置的密码（或私人令牌）。

**手机打开样式乱？**  
本站已适配手机宽度；若仍乱，换 Chrome/Safari 再试。

**实在不想用 Gitee？**  
备选 GitHub Pages（可能慢）：新建开源仓库后，把 HTTPS 地址填进  
`部署到GiteePages.bat` 同款 git 命令即可。
