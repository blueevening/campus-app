# 在线展示站 · 部署说明（国内可用优先）

## 方案 0：本地网址（立刻能用，无需外网）

双击 **`本地网址预览.bat`**  
浏览器打开：`http://127.0.0.1:5173/`

- 适合答辩本机演示、发给同机查看
- 不是公网链接；关掉窗口服务就停

## 方案 1：Gitee Pages（国内推荐，可分享链接）

1. 打开 https://gitee.com 注册并登录
2. 新建仓库，例如 `campus-app-demo`（开源，不要勾选初始化 README）
3. 双击 **`部署到GiteePages.bat`**
4. 粘贴仓库 HTTPS 地址，等推送完成
5. 仓库页 → **服务 → Gitee Pages → 启动**
6. 得到类似：`https://你的用户名.gitee.io/campus-app-demo/`

## 方案 2：GitHub Pages（国际常用）

1. GitHub 新建空仓库 `campus-app-demo`
2. 在本目录执行：

```powershell
git init
git add .
git commit -m "Campus app site"
git branch -M main
git remote add origin https://github.com/<用户名>/campus-app-demo.git
git push -u origin main
```

3. Settings → Pages → Deploy from branch → main / root  
4. 地址：`https://<用户名>.github.io/campus-app-demo/`

## 方案 3：Netlify Drop（国外，可能转圈）

打开 https://app.netlify.com/drop 拖文件夹。  
国内网络经常加载很慢，**不推荐作为唯一方案**。

## 最快怎么选？

| 你的情况 | 用哪个 |
|----------|--------|
| 马上给老师看、本机演示 | 方案 0 本地网址 |
| 要发给别人点开 | 方案 1 Gitee Pages |
| 有 GitHub 且对方在外网 | 方案 2 |

## 文件说明

| 文件 | 作用 |
|------|------|
| `本地网址预览.bat` | 一键起本地服务并打开浏览器 |
| `部署到GiteePages.bat` | 初始化 git 并推到 Gitee |
| `一键部署.bat` | 菜单（Netlify/打包等） |
| `serve-local.js` | 本地静态服务器 |
| `campus-app-site.zip` | 手动上传用压缩包 |
