# 校园综合服务App的设计与实现

## 摘要

随着移动互联网技术的快速发展，智能手机已经成为大学生日常生活中不可或缺的工具。然而，目前高校的各类服务系统相对分散，学生需要在多个系统之间切换才能完成课表查询、成绩查询、图书借阅等日常操作，给学生的学习和生活带来了不便。

本毕业设计针对上述问题，设计并实现了一款校园综合服务App。该App基于Vue.js前端框架和Spring Boot后端框架，采用前后端分离的架构设计，集成了课程表管理、成绩查询、图书馆服务、校园资讯浏览和失物招领等多个功能模块。系统采用MySQL数据库存储数据，使用MyBatis-Plus作为ORM框架，实现了高效的数据访问。前端使用Vant组件库，提供了良好的移动端用户体验。

经过测试，本系统功能完善、运行稳定、界面友好，能够有效满足大学生的日常校园服务需求，具有一定的实用价值和推广意义。

**关键词：** 校园服务；移动应用；Vue.js；Spring Boot；前后端分离

## Abstract

With the rapid development of mobile Internet technology, smartphones have become an indispensable tool in the daily life of college students. However, the current service systems in universities are relatively scattered, and students need to switch between multiple systems to complete daily operations such as course schedule inquiry, grade inquiry, and book borrowing, which brings inconvenience to students' study and life.

This graduation project designs and implements a campus comprehensive service App to address the above problems. The App is based on the Vue.js front-end framework and Spring Boot back-end framework, adopts a front-end and back-end separated architecture design, and integrates multiple functional modules such as course schedule management, grade inquiry, library services, campus news browsing, and lost and found. The system uses MySQL database to store data and MyBatis-Plus as the ORM framework to achieve efficient data access. The front-end uses the Vant component library to provide a good mobile user experience.

After testing, the system has complete functions, stable operation, and friendly interface, which can effectively meet the daily campus service needs of college students, and has certain practical value and promotion significance.

**Keywords:** Campus Services; Mobile Application; Vue.js; Spring Boot; Front-end and Back-end Separation

## 第一章 绪论

### 1.1 选题背景

近年来，随着移动互联网技术的飞速发展和智能手机的全面普及，移动应用已经深入到人们生活的方方面面。根据中国互联网络信息中心（CNNIC）发布的统计报告，截至2024年，我国手机网民规模已超过10亿，移动互联网普及率达到75%以上。在高校校园中，智能手机更是成为大学生学习、生活、社交的重要工具。

然而，目前大多数高校的信息化建设仍然存在一些问题。各类校园服务系统相对独立，如教务系统、图书管理系统、校园资讯平台等，学生需要在不同的系统之间频繁切换，操作繁琐且效率低下。同时，部分系统的移动端适配不足，用户体验较差，难以满足学生随时随地获取服务的需求。

在此背景下，开发一款集成多种校园服务功能的移动应用显得尤为必要。通过将课表查询、成绩查询、图书借阅、校园资讯、失物招领等功能整合到一个App中，可以为学生提供一站式校园服务，提高学生的学习和生活效率。

### 1.2 研究意义

本课题的研究具有以下几方面的意义：

**（1）理论意义**

本课题的研究将移动应用开发技术与校园服务需求相结合，探索了前后端分离架构在校园服务类应用中的应用模式。通过实践验证了Vue.js + Spring Boot技术栈在开发中小型移动Web应用中的可行性和优势，为同类系统的开发提供了参考。

**（2）实践意义**

从实践角度看，本系统的开发可以有效解决高校校园服务分散、操作繁琐的问题。通过整合多种服务功能，学生可以方便地查询课表、成绩，借阅图书，浏览校园资讯，发布失物招领信息等，大大提高了校园生活的便利性。

## 第二章 相关技术与工具

### 2.1 前端技术

#### 2.1.1 Vue.js框架

Vue.js是一套用于构建用户界面的渐进式JavaScript框架。与其它大型框架不同的是，Vue被设计为可以自底向上逐层应用。Vue的核心库只关注视图层，不仅易于上手，还便于与第三方库或既有项目整合。

Vue.js的主要特点包括：

1. **响应式数据绑定：** Vue.js使用响应式数据绑定系统，当数据变化时，视图会自动更新。

2. **组件化开发：** Vue.js采用组件化开发思想，将页面拆分为多个可复用的组件。

3. **虚拟DOM：** Vue.js使用虚拟DOM技术，提高了页面渲染性能。

4. **丰富的生态系统：** Vue.js拥有Vue Router、Vuex等官方工具，以及大量的第三方组件库。

本系统采用Vue 3.x版本进行前端开发，利用其Composition API特性，提高了代码的可维护性和复用性。

#### 2.1.2 Vant组件库

Vant是有赞前端团队开源的移动端Vue组件库，于2017年开源。Vant提供了丰富的移动端组件，如按钮、表单、弹出层、标签页等，可以帮助开发者快速搭建移动端应用。

Vant的主要特点包括：

1. **组件丰富：** 提供60+个高质量组件，覆盖移动端各类场景。

2. **按需引入：** 支持按需引入，减小打包体积。

3. **主题定制：** 支持主题定制，满足不同项目的视觉需求。

4. **TypeScript支持：** 使用TypeScript编写，提供完整的类型定义。

5. **国际化：** 支持多语言，满足不同地区的需求。

#### 2.1.3 Axios

Axios是一个基于Promise的HTTP客户端，用于浏览器和Node.js。它具有以下特点：

1. **支持浏览器和Node.js：** 可以在浏览器和Node.js环境中使用。

2. **支持Promise API：** 使用Promise处理异步请求，代码更加简洁。

3. **请求拦截和响应拦截：** 可以在请求发送前和响应接收后进行统一处理。

4. **自动转换JSON数据：** 自动将请求和响应数据转换为JSON格式。

5. **客户端支持防御XSRF：** 内置XSRF防御机制。

### 2.2 后端技术

#### 2.2.1 Spring Boot

Spring Boot是由Pivotal团队提供的全新框架，其目的是用来简化新Spring应用的初始搭建以及开发过程。该框架使用了特定的方式来进行配置，从而使开发人员不再需要定义样板化的配置。

Spring Boot的主要特点包括：

1. **自动配置：** Spring Boot会根据项目中的依赖自动配置Spring应用程序。

2. **起步依赖：** 提供了一系列起步依赖，简化了Maven/Gradle配置。

3. **内嵌服务器：** 内嵌Tomcat、Jetty等服务器，无需部署WAR文件。

4. **生产就绪特性：** 提供健康检查、度量指标、外部化配置等生产就绪特性。

5. **无代码生成和XML配置：** 不需要生成代码，也不需要XML配置。

#### 2.2.2 MyBatis-Plus

MyBatis-Plus是一个MyBatis的增强工具，在MyBatis的基础上只做增强不做改变，为简化开发、提高效率而生。

MyBatis-Plus的主要特性包括：

1. **无侵入：** 只做增强不做改变，引入它不会对现有工程产生影响。

2. **损耗小：** 启动即会自动注入基本CRUD，性能基本无损耗。

3. **强大的CRUD操作：** 内置通用Mapper、通用Service，仅通过少量配置即可实现大部分单表CRUD操作。

4. **支持Lambda形式调用：** 通过Lambda表达式，方便的编写各类查询条件。

5. **支持主键自动生成：** 支持多达4种主键策略。

6. **内置分页插件：** 基于物理分页，开发者无需关心具体操作。

#### 2.2.3 JWT

JWT（JSON Web Token）是一种开放标准（RFC 7519），它定义了一种紧凑的、自包含的方式，用于在各方之间安全地将信息作为JSON对象传输。

JWT的主要特点包括：

1. **紧凑性：** JWT体积小，可以通过URL、POST参数或HTTP头部发送。

2. **自包含：** JWT包含了所有需要的信息，避免了多次查询数据库。

3. **跨语言支持：** JWT使用JSON格式，几乎所有编程语言都支持。

4. **安全性：** JWT可以使用密钥进行签名，确保数据不被篡改。

### 2.3 数据库技术

#### 2.3.1 MySQL

MySQL是最流行的关系型数据库管理系统之一，由瑞典MySQL AB公司开发，目前属于Oracle公司。MySQL的主要特点包括：

1. **开源免费：** MySQL是开源软件，可以免费使用。

2. **性能优越：** MySQL具有优秀的性能，能够处理大规模数据。

3. **易于使用：** MySQL的安装、配置和使用都非常简单。

4. **跨平台支持：** MySQL支持多种操作系统，如Windows、Linux、macOS等。

5. **丰富的功能：** MySQL支持事务处理、存储过程、触发器、视图等高级功能。

#### 2.3.2 Redis（可选）

Redis是一个开源的使用ANSI C语言编写、支持网络、可基于内存亦可持久化的日志型、Key-Value数据库。Redis的主要特点包括：

1. **高性能：** Redis的数据存储在内存中，读写速度极快。

2. **丰富的数据结构：** Redis支持字符串、哈希、列表、集合、有序集合等多种数据结构。

3. **持久化支持：** Redis支持将内存中的数据持久化到磁盘。

4. **支持主从复制：** Redis支持主从复制，实现数据备份和读写分离。

Visual Studio Code（简称VS Code）是微软推出的一款免费、开源的代码编辑器。它具有以下特点：

## 第三章 需求分析

### 3.1 系统功能需求

根据对大学生校园服务需求的调研和分析，本系统需要实现以下功能：

#### 3.1.1 用户管理

用户管理是系统的基础功能，主要包括：

1. **用户注册：** 新用户可以通过学号、姓名、密码等信息进行注册。

2. **用户登录：** 已注册用户可以通过学号和密码登录系统。

3. **个人信息管理：** 用户可以查看和修改个人信息，如姓名、手机号、邮箱等。

4. **密码管理：** 用户可以修改登录密码。

#### 3.1.2 课程表管理

课程表管理是系统的核心功能之一，主要包括：

1. **课表查询：** 用户可以查看本学期的课程表，支持按周查看。

2. **课程详情：** 用户可以查看课程的详细信息，如教师、地点、时间等。

3. **选课功能：** 用户可以进行选课和退课操作。

4. **学期切换：** 用户可以切换不同学期的课表。

#### 3.1.3 成绩查询

成绩查询功能主要包括：

1. **成绩列表：** 用户可以查看各学期的成绩列表。

2. **成绩详情：** 用户可以查看成绩的详细信息，如平时成绩、期中成绩、期末成绩等。

3. **GPA计算：** 系统可以自动计算学生的平均绩点。

4. **学期筛选：** 用户可以按学期筛选成绩。

#### 3.1.4 图书馆服务

图书馆服务功能主要包括：

1. **图书查询：** 用户可以搜索图书，支持按书名、作者、ISBN等条件搜索。

2. **图书详情：** 用户可以查看图书的详细信息，如简介、库存、位置等。

3. **图书借阅：** 用户可以借阅图书。

4. **图书归还：** 用户可以归还已借阅的图书。

5. **借阅记录：** 用户可以查看自己的借阅记录。

6. **续借功能：** 用户可以对借阅的图书进行续借。

#### 3.1.5 校园资讯

校园资讯功能主要包括：

1. **资讯列表：** 用户可以浏览校园资讯列表。

2. **资讯详情：** 用户可以查看资讯的详细内容。

3. **分类筛选：** 用户可以按分类筛选资讯，如校园新闻、学术讲座、社团活动等。

4. **资讯发布：** 管理员可以发布新的校园资讯。

#### 3.1.6 失物招领

失物招领功能主要包括：

1. **信息浏览：** 用户可以浏览失物招领信息。

2. **发布信息：** 用户可以发布失物或拾获信息。

3. **信息筛选：** 用户可以按类型、分类等条件筛选信息。

#### 4.1.1 客户端层

客户端层负责与用户进行交互，主要包括：

1. **移动端H5：** 基于Vue.js开发的移动端Web应用，适配手机浏览器。

2. **微信小程序：** 基于微信小程序框架开发的应用（可扩展）。

3. **管理后台：** 基于Vue.js开发的PC端管理后台，供管理员使用。

#### 4.1.2 网关层

网关层使用Nginx作为反向代理服务器，主要功能包括：

1. **请求转发：** 将客户端请求转发到后端服务。

2. **负载均衡：** 在多个后端服务实例之间进行负载均衡。

3. **静态资源服务：** 提供前端静态资源的访问。

4. **SSL终结：** 处理HTTPS请求，保障数据传输安全。

#### 4.1.3 服务层

服务层是系统的核心，基于Spring Boot框架开发，主要包括：

1. **用户服务：** 处理用户注册、登录、信息管理等请求。

2. **课程服务：** 处理课表查询、选课、退课等请求。

3. **图书服务：** 处理图书查询、借阅、归还等请求。

4. **资讯服务：** 处理资讯浏览、发布等请求。

#### 4.1.4 数据层

数据层负责数据的存储和管理，主要包括：

1. **MySQL：** 关系型数据库，存储用户、课程、图书等结构化数据。

2. **Redis：** 缓存数据库，用于缓存热点数据，提高系统性能（可选）。

3. **文件存储：** 存储用户头像、图片等文件资源。

#### 4.2.1 用户管理模块

用户管理模块负责用户的注册、登录和信息管理，主要包括：

1. **用户注册：** 新用户可以通过学号、姓名、密码等信息进行注册。系统会验证学号的唯一性，确保每个学号只能注册一个账号。

2. **用户登录：** 已注册用户可以通过学号和密码登录系统。登录成功后，系统会生成JWT Token，用于后续的用户认证。

3. **个人信息管理：** 用户可以查看和修改个人信息，如姓名、手机号、邮箱、头像等。

4. **密码管理：** 用户可以修改登录密码，系统会验证旧密码的正确性。

#### 4.2.2 课程表模块

课程表模块负责课程信息的管理，主要包括：

1. **课表查询：** 用户可以查看本学期的课程表，支持按周查看。课程表以表格形式展示，直观清晰。

2. **课程详情：** 用户可以点击课程查看详细信息，如授课教师、上课地点、上课时间、学分等。

3. **选课管理：** 用户可以进行选课和退课操作。选课时，系统会检查课程容量，防止超额选课。

4. **学期切换：** 用户可以切换不同学期的课表，查看历史学期的课程信息。

#### 4.2.3 成绩查询模块

成绩查询模块负责成绩信息的查询和统计，主要包括：

1. **成绩列表：** 用户可以查看各学期的成绩列表，包括课程名称、学分、成绩等信息。

2. **成绩详情：** 用户可以查看成绩的详细信息，如平时成绩、期中成绩、期末成绩等。

3. **GPA计算：** 系统会自动计算学生的平均绩点（GPA），帮助学生了解学业情况。

4. **学期筛选：** 用户可以按学期筛选成绩，查看特定学期的成绩信息。

#### 4.2.4 图书馆模块

图书馆模块提供图书查询和借阅服务，主要包括：

1. **图书查询：** 用户可以搜索图书，支持按书名、作者、ISBN等条件搜索。搜索结果以列表形式展示，包含图书封面、书名、作者、库存等信息。

2. **图书详情：** 用户可以查看图书的详细信息，如出版社、出版日期、简介、馆藏位置、可借数量等。

3. **图书借阅：** 用户可以借阅图书。借阅时，系统会检查图书库存和用户借阅数量，确保借阅操作的合法性。

4. **图书归还：** 用户可以归还已借阅的图书。归还后，系统会更新图书库存和借阅记录状态。

5. **借阅记录：** 用户可以查看自己的借阅记录，包括借阅日期、应还日期、归还日期等信息。

6. **续借功能：** 用户可以对借阅的图书进行续借，延长还书期限。每本图书最多可续借2次。

#### 4.2.5 校园资讯模块

校园资讯模块负责校园信息的发布和浏览，主要包括：

1. **资讯列表：** 用户可以浏览校园资讯列表，资讯按发布时间倒序排列。列表显示资讯标题、摘要、发布时间等信息。

2. **资讯详情：** 用户可以查看资讯的详细内容。详情页显示资讯的完整内容、发布时间、浏览次数等信息。

3. **分类筛选：** 用户可以按分类筛选资讯，如校园新闻、学术讲座、社团活动、通知公告等。

4. **资讯发布：** 管理员可以发布新的校园资讯，包括标题、内容、分类、封面图片等信息。

#### 4.2.6 失物招领模块

失物招领模块提供失物和拾获信息的发布和查询服务，主要包括：

1. **信息浏览：** 用户可以浏览失物招领信息，信息按发布时间倒序排列。列表显示信息标题、类型、地点、发布时间等信息。

2. **信息发布：** 用户可以发布失物或拾获信息，包括标题、描述、类型、分类、地点、联系方式等信息。

3. **信息筛选：** 用户可以按类型（失物/拾获）、分类（证件/电子设备/书籍/衣物/其他）等条件筛选信息。

4. **状态更新：** 用户可以更新失物招领信息的状态，如标记为已认领、已关闭等。

```java
 * 用户登录

@Override
public Result<Map<String, Object>> login(String studentId, String password) {
    // 参数校验
    if (!StringUtils.hasText(studentId) || !StringUtils.hasText(password)) {
        return Result.error("学号和密码不能为空");
    }

    // 查询用户
    User user = findByStudentId(studentId);
    if (user == null) {
        return Result.error("用户不存在");
    }

    // 验证密码
    String encryptedPassword = DigestUtils.md5DigestAsHex(password.getBytes());
    if (!encryptedPassword.equals(user.getPassword())) {
        return Result.error("密码错误");
    }

    // 检查用户状态
    if (user.getStatus() == 0) {
        return Result.error("账号已被禁用");
    }

    // 生成Token
    String token = jwtUtils.generateToken(user.getId(), user.getUsername(), user.getRole());

    // 返回结果
    Map<String, Object> result = new HashMap<>();
    result.put("token", token);
    result.put("userId", user.getId());
    result.put("username", user.getUsername());
    result.put("studentId", user.getStudentId());
    result.put("role", user.getRole());
    result.put("avatar", user.getAvatar());

    return Result.success("登录成功", result);
}
```

```java
    List<Score> scores = getAllScores(studentId);
    
    double totalGPA = 0;
    double totalCredits = 0;
    int passedCourses = 0;
    double totalScore = 0;
    
    for (Score score : scores) {
        if (score.getTotalScore() != null && score.getTotalScore() >= 60) {
            totalGPA += score.getGpa().doubleValue() * score.getCredit();
            totalCredits += score.getCredit();
            passedCourses++;
            totalScore += score.getTotalScore().doubleValue();
        }
    }
    
    Map<String, Object> result = new HashMap<>();
    result.put("averageGPA", totalCredits > 0 ? Math.round(totalGPA / totalCredits * 100) / 100.0 : 0);
    result.put("totalCredits", totalCredits);
    result.put("passedCourses", passedCourses);
    result.put("averageScore", passedCourses > 0 ? Math.round(totalScore / passedCourses * 100) / 100.0 : 0);
    
    return result;
}
```

```java
    }

    }

    LambdaQueryWrapper<BookReservation> wrapper = new LambdaQueryWrapper<>();
    wrapper.eq(BookReservation::getUserId, userId);
    wrapper.eq(BookReservation::getStatus, 1); // 借阅中
    long count = bookReservationMapper.selectCount(wrapper);
    if (count >= 5) {
        return Result.error("借阅数量已达上限");
    }
    
    // 创建借阅记录
    BookReservation reservation = new BookReservation();
    reservation.setUserId(userId);
    reservation.setBookId(bookId);
    reservation.setBorrowDate(LocalDateTime.now());
    reservation.setDueDate(LocalDateTime.now().plusDays(30));
    reservation.setStatus(1); // 借阅中
    reservation.setRenewCount(0);
    bookReservationMapper.insert(reservation);
    
    // 更新图书库存
    book.setAvailableCopies(book.getAvailableCopies() - 1);
```

#### 5.4.1 JWT认证实现

JWT认证是本系统的关键技术之一，用于实现用户身份验证和授权。实现过程如下：

1. **生成Token：** 用户登录成功后，使用JWT生成Token，包含用户ID、用户名、角色等信息。

2. **Token验证：** 每次请求时，从请求头中获取Token，验证Token的有效性。

3. **权限控制：** 根据Token中的角色信息，判断用户是否有权限访问特定资源。

```java
/**
 * JWT工具类
 */
@Component
public class JwtUtils {

    @Value("${jwt.secret}")
    private String secret;

    @Value("${jwt.expiration}")
    private Long expiration;

    /**
     * 生成JWT Token
     */
    public String generateToken(Long userId, String username, Integer role) {
        Map<String, Object> claims = new HashMap<>();
        claims.put("userId", userId);
        claims.put("username", username);
        claims.put("role", role);

        return Jwts.builder()
                .setClaims(claims)
                .setSubject(userId.toString())
                .setIssuedAt(new Date())
                .setExpiration(new Date(System.currentTimeMillis() + expiration))
                .signWith(SignatureAlgorithm.HS512, secret)
                .compact();
    }

    /**
     * 验证Token是否有效
     */
    public Boolean validateToken(String token) {
        return getClaimsFromToken(token) != null && !isTokenExpired(token);
    }
}
```

Vue.js的响应式数据绑定是前端开发的核心技术。在本系统中，我们使用Vue 3的Composition API实现响应式数据绑定：

```javascript
import { ref, computed, onMounted } from 'vue'
import { useRouter } from 'vue-router'
import { useStore } from 'vuex'
import { courseApi } from '../api'

export default {
  name: 'Course',
  setup() {
    const router = useRouter()
    const store = useStore()
    const courses = ref([])
    const currentSemester = ref(store.getters.getCurrentSemester)

    // 计算属性
    const hasCourse = (day, period) => {
      return courses.value.some(course => {
        const times = parseClassTime(course.classTime)
        return times.some(t => t.day === day && period >= t.start && period <= t.end)

    // 加载课程数据
    const loadCourses = async () => {

          semester: currentSemester.value
        })

      } catch (error) {
        showToast('获取课程失败')
      }
    }

    onMounted(() => {
      loadCourses()
    })

      courses,
```

## 第七章 结论与展望

### 7.1 总结

本毕业设计完成了校园综合服务App的设计与实现，主要完成了以下工作：

1. **需求调研与分析：** 通过问卷调查和访谈，了解了大学生对校园服务的需求，确定了系统的功能需求和非功能需求。

2. **系统设计：** 采用前后端分离的架构，设计了系统的整体架构、功能模块、数据库结构和接口规范。

3. **系统实现：** 基于Vue.js和Spring Boot技术栈，实现了用户管理、课程表管理、成绩查询、图书馆服务、校园资讯和失物招领等功能模块。

4. **系统测试：** 对系统进行了功能测试、性能测试和兼容性测试，验证了系统的质量。

通过本项目的开发，取得了以下成果：

1. **技术成果：** 成功开发了一款功能完善的校园综合服务App，验证了Vue.js + Spring Boot技术栈在开发中小型移动Web应用中的可行性。

2. **实践成果：** 通过完整的软件开发流程实践，提高了软件开发能力、问题解决能力和项目管理能力。

3. **应用成果：** 本系统可以为大学生提供便捷的校园服务，具有一定的实用价值。

### 7.2 不足与展望

虽然本系统已经实现了预期的功能，但仍存在一些不足之处：

1. **功能方面：** 系统的功能还不够丰富，缺少一些高级功能，如推送通知、社交互动、数据分析等。

2. **性能方面：** 系统的性能还有优化空间，如可以引入Redis缓存、数据库优化等技术提高系统性能。

3. **安全方面：** 系统的安全性还需要加强，如可以引入更完善的权限控制、数据加密等安全机制。

4. **用户体验方面：** 系统的用户体验还有提升空间，如可以优化界面设计、增加动画效果、提供个性化推荐等。

针对以上不足，未来的改进方向包括：

1. **功能扩展：** 增加推送通知、社交互动、数据分析等功能，丰富系统的功能。

2. **性能优化：** 引入Redis缓存、数据库优化、CDN加速等技术，提高系统的性能。

3. **安全加固：** 引入更完善的权限控制、数据加密、安全审计等机制，提高系统的安全性。

4. **用户体验提升：** 优化界面设计、增加动画效果、提供个性化推荐，提升用户体验。

5. **平台扩展：** 开发微信小程序版本和原生App版本，扩大系统的覆盖范围。
