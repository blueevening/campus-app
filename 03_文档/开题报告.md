# 毕业设计（论文）开题报告

## 一、选题背景与意义

### 1.1 选题背景

随着移动互联网技术的快速发展和智能手机的全面普及，移动应用已经深入到人们生活的方方面面。根据中国互联网络信息中心（CNNIC）发布的统计报告，截至2024年，我国手机网民规模已超过10亿，移动互联网普及率达到75%以上。在高校校园中，智能手机更是成为大学生学习、生活、社交的重要工具。

然而，目前大多数高校的信息化建设仍然存在一些问题。各类校园服务系统相对独立，如教务系统、图书管理系统、校园资讯平台等，学生需要在不同的系统之间频繁切换，操作繁琐且效率低下。同时，部分系统的移动端适配不足，用户体验较差，难以满足学生随时随地获取服务的需求。

在此背景下，开发一款集成多种校园服务功能的移动应用显得尤为必要。通过将课表查询、成绩查询、图书借阅、校园资讯、失物招领等功能整合到一个App中，可以为学生提供一站式校园服务，提高学生的学习和生活效率。

### 1.2 研究意义

本课题的研究具有以下几方面的意义：

**（1）理论意义**

本课题的研究将移动应用开发技术与校园服务需求相结合，探索了前后端分离架构在校园服务类应用中的应用模式。通过实践验证了Vue.js + Spring Boot技术栈在开发中小型移动Web应用中的可行性和优势，为同类系统的开发提供了参考。

**（2）实践意义**

从实践角度看，本系统的开发可以有效解决高校校园服务分散、操作繁琐的问题。通过整合多种服务功能，学生可以方便地查询课表、成绩，借阅图书，浏览校园资讯，发布失物招领信息等，大大提高了校园生活的便利性。

**（3）技术意义**

从技术角度看，本课题的开发过程涵盖了需求分析、系统设计、编码实现、测试部署等软件开发的完整流程，是对所学专业知识的综合运用和实践。通过本项目的开发，可以提高软件开发能力、问题解决能力和项目管理能力。

## 二、国内外研究现状

### 2.1 国外研究现状

在国外，高校信息化建设起步较早，许多知名大学都开发了自己的校园移动应用。例如，美国斯坦福大学的Stanford Mobile、麻省理工学院的MIT Mobile等，这些应用集成了课程管理、校园地图、活动通知等多种功能，为师生提供了便捷的校园服务。

在技术实现方面，国外的校园应用开发逐渐从原生开发向跨平台开发转变。React Native、Flutter等跨平台框架因其开发效率高、维护成本低等优势，在校园应用开发中得到了广泛应用。

### 2.2 国内研究现状

在国内，随着移动互联网的发展，越来越多的高校开始重视校园移动应用的开发。一些高校与企业合作，开发了功能完善的校园综合服务平台，如"今日校园"、"智慧校园"等。这些平台通常集成了课表查询、成绩查询、一卡通服务、校园资讯等功能，为学生提供了便利。

在技术实现方面，国内校园应用开发主要采用以下几种技术路线：
- 基于微信小程序的轻量级应用
- 基于uni-app的跨平台应用
- 基于Android/iOS的原生应用
- 基于Web技术的H5应用

其中，基于Vue.js的Web应用和小程序因其开发成本低、易于维护等优势，在中小型校园应用中得到了广泛应用。

## 三、研究内容与方法

### 3.1 研究内容

本课题的主要研究内容包括：

1. **需求调研与分析：** 通过问卷调查、访谈等方式，了解大学生对校园服务的需求，确定系统的功能需求和非功能需求。

2. **系统设计：** 根据需求分析结果，进行系统架构设计、功能模块设计、数据库设计和界面设计。

3. **系统实现：** 基于Vue.js和Spring Boot技术栈，实现课程表管理、成绩查询、图书馆服务、校园资讯和失物招领等功能模块。

4. **系统测试：** 对系统进行功能测试、性能测试和兼容性测试，确保系统质量。

### 3.2 研究方法

本课题采用以下研究方法：

1. **文献研究法：** 通过查阅相关文献，了解校园服务系统的发展现状和技术趋势。

2. **调查研究法：** 通过问卷调查和访谈，了解用户的实际需求。

3. **实验研究法：** 通过系统开发和测试，验证技术方案的可行性。

4. **案例分析法：** 参考已有的校园服务系统案例，借鉴其成功经验。

## 四、技术路线

本系统的技术路线如下：

### 4.1 前端技术选型

- **框架：** Vue.js 3.x
- **UI组件库：** Vant 4.x
- **HTTP客户端：** Axios
- **路由管理：** Vue Router 4.x
- **状态管理：** Vuex 4.x

### 4.2 后端技术选型

- **框架：** Spring Boot 2.7.x
- **ORM框架：** MyBatis-Plus 3.5.x
- **数据库：** MySQL 8.0
- **认证方式：** JWT
- **接口文档：** Swagger

### 4.3 开发工具

- **前端IDE：** Visual Studio Code
- **后端IDE：** IntelliJ IDEA
- **数据库工具：** Navicat
- **版本控制：** Git
- **接口测试：** Postman

## 五、可行性分析

### 5.1 技术可行性

本系统采用的Vue.js和Spring Boot都是成熟的技术框架，拥有丰富的文档和社区支持。Vue.js是国内最流行的前端框架之一，学习曲线平缓，适合快速开发。Spring Boot是Java生态中最流行的后端框架，具有自动配置、起步依赖等特性，能够提高开发效率。

此外，MyBatis-Plus、Vant等组件库也为开发提供了便利。这些技术在实际项目中得到了广泛应用，技术成熟度高，能够满足本系统的开发需求。

### 5.2 经济可行性

本系统的开发主要使用开源技术，不需要购买商业软件。开发工具如VS Code、IntelliJ IDEA Community Edition等都可以免费使用。服务器可以使用学校的实验设备或云服务器的免费额度。因此，本系统的开发成本较低，具有经济可行性。

### 5.3 操作可行性

本系统采用Web技术开发，用户可以通过浏览器访问，不需要安装额外的软件。系统界面简洁友好，操作流程简单直观，用户学习成本低。同时，系统提供了详细的使用说明和帮助文档，方便用户使用。
