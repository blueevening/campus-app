## 二、设计目的与要求

### 2.1 设计目的

本毕业设计的目的是设计并实现一款校园综合服务App，通过整合课程表查询、成绩查询、图书馆服务、校园资讯浏览和失物招领等功能，为大学生提供一站式校园服务平台，提高学生的学习和生活效率。

通过本毕业设计，达到以下教学目标：

1. 综合运用所学的专业知识，培养分析问题和解决问题的能力。
2. 掌握移动应用开发的基本流程和方法，提高软件开发能力。
3. 熟悉前后端分离的开发模式，掌握Vue.js和Spring Boot技术栈的应用。
4. 培养文档撰写能力和团队协作能力。

### 2.2 设计要求

1. **功能要求：**
   - 实现用户注册、登录、个人信息管理等功能
   - 实现课程表查询、选课、退课等功能
   - 实现成绩查询、GPA计算等功能
   - 实现图书查询、借阅、归还、续借等功能
   - 实现校园资讯浏览、发布等功能
   - 实现失物招领信息发布、查询等功能

2. **技术要求：**
   - 前端采用Vue.js框架，使用Vant组件库
   - 后端采用Spring Boot框架，使用MyBatis-Plus作为ORM框架
   - 数据库采用MySQL
   - 采用JWT进行用户认证
   - 实现RESTful风格的API接口

3. **文档要求：**
   - 撰写完整的毕业设计论文，字数不少于5000字
   - 论文格式符合学校要求
   - 提供系统设计文档、数据库设计文档等

4. **其他要求：**
   - 系统能够正常运行，功能完整
   - 界面友好，操作便捷
   - 代码规范，注释完整

## 三、设计内容与任务

### 3.1 主要设计内容

1. **需求分析**
   - 调研大学生对校园服务的需求
   - 确定系统的功能需求和非功能需求
   - 绘制用例图

2. **系统设计**
   - 设计系统整体架构
   - 设计功能模块
   - 设计数据库结构
   - 设计API接口
   - 设计系统界面

3. **系统实现**
   - 搭建开发环境
   - 实现后端服务
   - 实现前端应用
   - 进行系统集成

4. **系统测试**
   - 制定测试计划
   - 执行功能测试
   - 执行性能测试
   - 编写测试报告

5. **论文撰写**
   - 撰写毕业设计论文
   - 整理设计文档
   - 准备答辩材料

## 六、指导教师职责

1. 帮助学生确定毕业设计题目，明确设计要求。
2. 指导学生进行文献调研和需求分析。
3. 审核学生的系统设计方案。
4. 定期检查学生的开发进度，解答技术问题。
5. 指导学生撰写毕业设计论文。
6. 评阅毕业设计论文，给出成绩。

## 七、学生职责

1. 按照任务书要求，按时完成各阶段的工作任务。
2. 主动与指导教师沟通，汇报工作进展。
3. 独立完成毕业设计工作，不得抄袭。
4. 按照学校要求撰写毕业设计论文。
5. 按时参加毕业设计答辩。
