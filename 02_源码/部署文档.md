# 校园综合服务网站部署文档

## 一、环境要求

### 1.1 服务器环境

| 软件 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 1.8 或更高 | Java开发环境 |
| Maven | 3.6 或更高 | 项目构建工具 |
| Node.js | 16.x 或更高 | 前端运行环境 |
| MySQL | 8.0 或更高 | 数据库 |
| Nginx | 1.20 或更高 | 反向代理服务器（可选） |

### 1.2 开发工具

| 工具 | 用途 |
|------|------|
| IntelliJ IDEA / Eclipse | Java后端开发 |
| Visual Studio Code | 前端开发 |
| Navicat / MySQL Workbench | 数据库管理 |
| Postman | 接口测试 |

## 二、数据库部署

### 2.1 创建数据库

1. 打开MySQL客户端（命令行或Navicat）。

2. 执行数据库创建脚本：
   ```bash
   mysql -u root -p < campus_app.sql
   ```

3. 或者手动执行SQL脚本：
   ```sql
   -- 登录MySQL
   mysql -u root -p
   
   -- 执行脚本
   source /path/to/campus_app.sql
   ```

### 2.2 验证数据库

执行以下命令验证数据库创建成功：

```sql
-- 查看数据库
SHOW DATABASES;

-- 使用数据库
USE campus_app;

-- 查看表
SHOW TABLES;

-- 查看测试数据
SELECT * FROM sys_user;
```

## 三、后端部署

### 3.1 修改配置文件

1. 打开后端项目目录 `campus-app-backend`。

2. 编辑配置文件 `src/main/resources/application.yml`。

3. 修改数据库连接信息：
   ```yaml
   spring:
     datasource:
       url: jdbc:mysql://localhost:3306/campus_app?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai
       username: root
       password: 123456  # 修改为实际密码
   ```

4. 修改JWT密钥（可选）：
   ```yaml
   jwt:
     secret: your-secret-key  # 修改为自定义密钥
     expiration: 86400000
   ```

### 3.2 打包项目

1. 打开命令行，进入后端项目目录：
   ```bash
   cd campus-app-backend
   ```

2. 执行Maven打包命令：
   ```bash
   mvn clean package -DskipTests
   ```

3. 打包成功后，在 `target` 目录下生成 `campus-app-backend-1.0.0.jar` 文件。

### 3.3 运行项目

**方式一：直接运行**

```bash
java -jar target/campus-app-backend-1.0.0.jar
```

**方式二：后台运行**

```bash
nohup java -jar target/campus-app-backend-1.0.0.jar > app.log 2>&1 &
```

**方式三：指定端口运行**

```bash
java -jar target/campus-app-backend-1.0.0.jar --server.port=8080
```

### 3.4 验证后端服务

1. 打开浏览器或Postman。

2. 访问以下地址验证服务是否启动成功：
   ```
   http://localhost:8080/api/user/login
   ```

## 四、前端部署

### 4.1 修改配置文件

1. 打开前端项目目录 `campus-app-frontend`。

2. 编辑配置文件 `.env.production`（如果没有则创建）：
   ```
   VUE_APP_API_URL=http://your-server-ip:8080/api
   ```

3. 修改 `vue.config.js` 中的代理配置（开发环境）：
   ```javascript
   module.exports = {
     devServer: {
       proxy: {
         '/api': {
           target: 'http://localhost:8080',
           changeOrigin: true
         }
       }
     }
   }
   ```

### 4.2 安装依赖

```bash
cd campus-app-frontend
npm install
```

### 4.3 打包项目

```bash
npm run build
```

打包成功后，在项目根目录下生成 `dist` 文件夹，包含所有静态资源。

### 4.4 部署静态资源

**方式一：使用Nginx部署**

1. 安装Nginx（如果未安装）：
   ```bash
   # Ubuntu/Debian
   sudo apt-get install nginx
   
   # CentOS
   sudo yum install nginx
   ```

2. 复制静态资源到Nginx目录：
   ```bash
   cp -r dist/* /usr/share/nginx/html/
   ```

3. 配置Nginx：
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           root /usr/share/nginx/html;
           index index.html;
           try_files $uri $uri/ /index.html;
       }
       
       location /api {
           proxy_pass http://localhost:8080;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
       }
   }
   ```

4. 重启Nginx：
   ```bash
   sudo systemctl restart nginx
   ```

**方式二：使用Node.js部署**

1. 安装 `serve`：
   ```bash
   npm install -g serve
   ```

2. 运行静态资源服务器：
   ```bash
   serve -s dist -l 3000
   ```

## 五、常见问题排查

### 5.1 数据库连接失败

**问题描述：** 启动后端服务时提示数据库连接失败。

**解决方案：**
1. 检查MySQL服务是否启动。
2. 检查数据库连接信息是否正确（用户名、密码、端口）。
3. 检查防火墙是否允许3306端口。

### 5.2 端口被占用

**问题描述：** 启动服务时提示端口被占用。

**解决方案：**
1. 查找占用端口的进程：
   ```bash
   # Windows
   netstat -ano | findstr :8080
   
   # Linux/Mac
   lsof -i :8080
   ```

2. 终止占用端口的进程，或修改服务端口。

### 5.3 前端无法访问后端API

**问题描述：** 前端页面加载正常，但无法获取数据。

**解决方案：**
1. 检查后端服务是否正常运行。
2. 检查API地址配置是否正确。
3. 检查是否存在跨域问题。
4. 检查浏览器控制台是否有错误信息。

### 5.4 页面白屏

**问题描述：** 访问前端页面时显示白屏。

**解决方案：**
1. 检查静态资源是否正确部署。
2. 检查Nginx配置是否正确。
3. 检查浏览器控制台是否有错误信息。
4. 清除浏览器缓存后重试。
