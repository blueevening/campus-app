# 校园综合服务App - 毕业设计

## 项目简介

本项目是一款校园综合服务App，为大学生提供一站式校园服务平台。系统集成了课程表管理、成绩查询、图书馆服务、校园资讯、失物招领、第二课堂等功能。

**视觉风格**：现代校园风 —— 深蓝主色、浅雾背景、金色点缀，统一卡片与圆角组件。

## 功能特性

### 学习服务
- **课程表**：查看课程安排，支持选课、退课、学期切换
- **成绩查询**：查看各学期成绩，自动计算GPA
- **图书馆**：搜索图书、借阅、归还、续借、预约
- **借阅记录**：查看图书借阅历史

### 校园生活
- **校园资讯**：浏览和发布校园新闻
- **失物招领**：发布和查找失物信息
- **第二课堂**：参与活动获取积分，目标120分，含签到/完成闭环
- **证书申请**：上传证书获取积分（国家级20分、省级15分、市级10分、校级5分、院级3分、其他2分）
- **消息通知**：系统公告与业务提醒

### 个人中心
- **个人资料**：查看和编辑个人信息
- **修改密码**：修改登录密码（含二次确认）
- **学分看板**：第二课堂积分与诚信值

### 管理端
- **用户管理**：启用/停用、重置密码、任命班长
- **成绩录入**：录入成绩并自动计算 GPA
- **内容审核**：资讯/失物可见性管理

## 技术栈

### 前端
- Vue.js 3.x
- Vant 4.x（移动端UI组件库）
- Vue Router 4.x（Hash 模式，便于静态托管）
- Vuex 4.x
- Axios
- 浏览器内 Mock（静态演示无需后端）

### 后端
- Node.js（原生 `http` 模块模拟 REST API）
- HMAC Token 鉴权
- 内存数据（演示环境；生产可替换 MySQL）

> 说明：密码采用 MD5 仅为演示简化，生产环境请改用 bcrypt/argon2。

## 快速开始

### 环境要求
- Node.js 16.x 或更高版本

### 启动后端（可选，联调用）
```bash
cd 02_源码/campus-app-backend
node server.js
# 监听 http://localhost:8080
```

### 启动前端
```bash
cd 02_源码/campus-app-frontend
npm install
npm run dev
# 监听 http://localhost:8081（以实际端口为准）
```

### 静态演示（无需后端）
默认启用浏览器 Mock，可直接构建后用任意静态服务器打开：
```bash
cd 02_源码/campus-app-frontend
npm run build
# 将 dist/ 部署到 GitHub Pages / Netlify / Vercel
```

### 在线静态展示站
仓库另附可分享的静态展示站（`09_在线展示站/`），无需后端即可演示核心流程。
