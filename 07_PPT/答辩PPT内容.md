## 第3页：选题背景

**背景：**
- 移动互联网快速发展，智能手机普及率超过75%
- 大学生日常依赖手机获取信息和服务
- 高校服务系统分散，操作繁琐

**问题：**
- 课表、成绩、图书等系统各自独立
- 需要频繁切换系统，效率低下
- 缺少第二课堂积分管理平台

**解决方案：**
- 开发一站式校园综合服务App
- 整合多种校园服务功能
- 集成第二课堂和证书管理系统

## 第4页：相关技术

**前端技术：**
- Vue.js 3.x - 渐进式JavaScript框架
- Vant 4.x - 移动端UI组件库
- Axios - HTTP请求库
- Vue Router - 路由管理
- Vuex - 状态管理

**后端技术：**
- Node.js - JavaScript运行环境
- Express - Web应用框架

**数据库：**
- MySQL 8.0 - 关系型数据库

## 第5页：需求分析

**功能需求：**

| 模块 | 功能 |
|------|------|
| 用户管理 | 注册、登录、信息管理 |
| 课程表 | 课表查询、选课、退课 |
| 成绩查询 | 成绩列表、GPA计算 |
| 图书馆 | 图书搜索、借阅、归还 |
| 校园资讯 | 资讯浏览、发布 |
| 失物招领 | 信息浏览、发布 |
| 第二课堂 | 活动参与、积分管理 |
| 证书申请 | 证书上传、积分获取 |

**非功能需求：**
- 性能：响应时间<500ms
- 安全：JWT认证、密码加密
- 兼容：支持主流浏览器和移动设备

## 第8页：系统实现-核心功能

**用户认证（JWT）：**
- 登录时生成Token
- 请求时验证Token
- 密码MD5加密存储

**课程表查询：**
- 联表查询学生选课信息
- JSON格式存储上课时间
- 支持学期切换

**图书借阅：**
- 库存检查、借阅数量限制
- 借阅记录管理、续借功能

---

## 第9页：系统实现-第二课堂

**第二课堂功能：**
- 活动发布（管理员）
- 活动报名、签到
- 积分发放（目标120分）
- 参与记录查询

**证书申请功能：**
- 证书等级：国家级(20分)、省级(15分)、市级(10分)、校级(5分)、院级(3分)、其他(2分)
- 证书类型：学科竞赛、科技创新、文体活动、社会实践、志愿服务
- 审核流程：申请→审核→积分发放

**诚信值系统：**
- 初始值：100分
- 低于80分需恢复
- 每次恢复+1分

## 第12页：技术难点与解决方案

**难点1：JWT认证**
- 问题：如何实现无状态用户认证？
- 方案：JWT Token + 拦截器验证

**难点2：第二课堂积分系统**
- 问题：如何管理复杂的积分规则？
- 方案：证书等级积分对照表 + 审核流程

**难点3：诚信值恢复机制**
- 问题：如何激励学生恢复诚信值？
- 方案：指定活动恢复，每次+1分

## 第13页：创新点

**1. 一站式校园服务**
- 整合课表、成绩、图书、资讯、失物招领
- 减少系统切换，提高使用效率

**2. 第二课堂积分管理**
- 活动参与获取积分
- 证书申请获取积分
- 目标120分，诚信值机制

**3. 移动端优先设计**
- 使用Vant组件库，适配移动设备
- 响应式布局，良好用户体验

**4. 专业配色方案**
- 采用高校风格深蓝/藏青配色
- 去除AI味，更专业稳重
